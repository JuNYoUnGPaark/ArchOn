운동 평가 방법

STEP1. 기기 점검 단계

  • 기준값 측정 버튼을 누르면 먼저 3초 동안 센서 연결 상태를 확인합니다.
  • 일부 센서가 불안정해도 전체 연결 비율이 충분하면 경고만 표시하고 진행합니다.
  • 아예 연결되지 않은 센서가 많으면 재연결 필요 창을 띄우고 측정을 중단합니다.

STEP2. 기준값 측정 단계

  • “발을 올리고 가만히 자세를 유지하세요” 메시지를 표시합니다.
  • 5초 동안 FSR 압력센서와 EMG 센서값을 수집합니다.
  • 수집된 값의 평균을 기준값으로 저장하고 화면의 기준값 란에 표시합니다.

STEP3. 최대 아치 형성값 측정 단계

  • 버튼이 최대 아치 형성값 측정으로 바뀝니다.
  • “엄지발가락을 최대한 들어올리세요” 메시지를 표시하고 5초 동안 측정합니다.
  • 실시간으로 기준값 대비 엄지 압력이 몇 % 감소했는지 보여줍니다.
  • 통과 조건은 엄지 압력 15% 이상 감소, 5초 동안 압력 변화율 70% 이하, 뒤꿈치 압력 변화 50% 이하입니다.

STEP4. MVIC 측정 단계

  • 3초씩 총 3회 측정합니다.
  • “아치를 유지하면서 엄지발가락으로 바닥을 최대한 강하게 누르세요” 메시지를 표시합니다.
  • 3회 측정값의 변동계수(CV = 표준편차 / 평균 × 100)가 60%를 초과하면 1회차부터 다시 측정합니다.
  • 통과하면 MVIC 기준값을 저장하고 운동 시작 단계로 넘어갑니다.

STEP5. 숏풋 운동 수행 및 평가 단계

  • 운동 시작 버튼을 누르면 측정이 시작되고, 처음 3초 동안은 운동 종료 버튼을 누를 수 없습니다.
  • 운동 종료를 누르면 운동 구간 전체를 분석합니다.
  • 아치 유지, 엄지 과보상 억제, 뒤꿈치 안정성, EMG 활성도 4개 항목을 평가합니다.

STEP6. 점수 계산 방식

  • 아치 유지: 35점
  • 엄지 과보상 억제: 25점
  • 뒤꿈치 안정성: 20점
  • EMG 활성도: 20점
  • 각 항목은 운동 중 조건을 만족한 샘플 비율에 가중치를 곱해 계산합니다.
  • 총점 80점 이상은 Good, 50점 이상은 Normal, 50점 미만은 Bad로 표시합니다.

STEP7. 반복 운동 및 전체 종료

  • 운동은 원하는 횟수만큼 반복할 수 있고, 매 회차 결과가 카드 형태로 운동 로그에 누적됩니다.
  • 전체 운동 종료 버튼을 누르면 JSON 요약 파일을 data 폴더에 저장합니다.
  • 저장 후 버튼은 다시 기준값 측정으로 돌아가며 새 세션을 바로 시작할 수 있습니다.
